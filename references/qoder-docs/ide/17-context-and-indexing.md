# 上下文压缩 与 代码库索引（Qoder IDE）

> 来源：/zh/user-guide/chat/smart-context-control + /zh/user-guide/indexing

## 上下文压缩

**Qoder IDE 当前支持 200K 上下文长度。**
压缩功能提供上下文窗口可见性，可实时查看当前会话用量。

| 手段 | 适用场景 | 效果 |
|---|---|---|
| **压缩当前会话（Compact Chat）** | 围绕同一主题持续深入，会话冗长、窗口快撑满 | 智能总结：保留关键代码逻辑与核心脉络，剔除冗余。**降低 Credits 消耗 + 提升响应速度** |
| **新建会话（New Chat）** | 切换到全新话题或任务（Bug 修复 → 新功能） | **更准**（摆脱无关历史干扰）+ **更省**（避免无关上下文浪费 Credits） |

> ⚠️ 压缩会影响生成质量，因此**两种情况下压缩被禁用**：
> - 对话早期阶段（节省的 Credits 少）
> - AI 正在生成回复时（会中断回复生成）

## 代码库索引

打开项目时自动为代码库建立索引（生成文件嵌入向量），支撑代码理解、智能推荐和**语义搜索**。
**增量索引**，新建/修改文件实时处理，无需人工干预。

### 配置

`⌘⇧,`（macOS）/ `Ctrl+Shift+,` → **Qoder IDE 设置 → 代码库索引**
- 手动启用：点「创建」
- 持续后台索引：把「**自动更新**」切为开启

> **支持最多 100,000 个文件的代码库。**
> < 10,000 个文件的代码库**自动更新默认开启**；更大的需要手动启用。

### 忽略文件

默认索引所有项目文件，**除了**：
- `.gitignore` 中指定的文件和目录
- **`.qoderignore`** 中列出的文件

自定义排除：设置 → 代码库索引 → 「忽略文件」旁点「管理」→ 添加模式。

| 格式 | 描述 |
|---|---|
| `config.json` | 忽略特定文件 |
| `dist/` | 忽略整个目录 |
| `*.log` | 忽略所有 `.log` 文件 |
| `**/logs` | 忽略任意嵌套层级中的 logs 目录 |
| `!app/` | **从忽略规则中排除某个路径（取反）** |

检查某文件是否被忽略：`git check-ignore -v [file]`

### FAQ

- **没有集中式索引列表**，只能在各项目的索引设置中查看
- **源代码不会存放在 Qoder 服务器上**

## 🎯 本项目应该做的一件事：加 `.qoderignore`

本项目 `references/` 下镜像了大量外部文档（trae-docs、llm-wiki、qoder-docs 本身），
这些是**参考资料，不是本项目知识**。它们被索引会：
- 稀释语义搜索结果（搜「用例规范」可能命中 Trae 文档）
- 污染 Repo Wiki 与知识卡片的模块划分（这正是当前 `.qoder/repowiki/` 生成结果失真的原因之一）

建议在项目根加 `.qoderignore`：
```
references/llm-wiki/trae-docs/
graphify-out/
```
`references/qoder-docs/` 是否排除取决于取舍 —— 它是我们要主动查阅的规格，
保留索引有利于语义搜索命中，可以不排。
