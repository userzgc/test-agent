# Plugins（Qoder IDE）

> 来源：https://docs.qoder.com/zh/extensions/plugins

## 是什么

**插件是 Skill、MCP、Agent、Command、Rule、Hook 的任意组合套件。**
安装一个插件即一次性引入一组协作能力。

## 可打包的 6 类组件

| 组件 | 描述 |
|------|------|
| **Skills** | 面向复杂任务的特定智能体能力 |
| **MCP Servers** | 连接外部服务的 MCP 集成 |
| **Agents** | 可被主 Agent 调度执行特定任务的子代理 |
| **Commands** | 斜杠命令，用户手动触发的快捷操作 |
| **Rules** | 注入 AI 上下文的行为与风格约束 |
| **Hooks** | 在特定事件节点自动执行的脚本 |

> ⚠️ 这是本项目最值得注意的一点：**`.trae/` 里 agents + skills + steering + hooks 四层资产，
> 在 Qoder 里可以打包成一个 Plugin 统一分发和启停**，不必逐个迁移+逐个管理。

## 安装与作用域

安装时可选生效范围：
- **User 级** — 对所有会话生效
- **Project 级** — 仅指定项目生效

**插件作为整体安装，不支持仅安装其中部分组件。** 安装后在 Editor 和 Quest 中均可用。

## 插件市场

入口：Quest 左侧导航底部「插件市场」，或 Qoder IDE 设置的「插件」面板右上角链接。

分类：Featured / Coding / DataBase / Workflow / DevOps / Product Design / Debug & Testing。

插件详情页可查看：组件列表（含哪些 Skill/MCP/Agent/Command/Rule/Hook）、
插件信息（分类标签、开发者、最近更新、源代码地址）。

## 自定义插件

- **创建**：市场右上角 **+ 创建插件** → 跳转 Chat 区并自动选中内置 `plugin-creator` Skill，对话引导创建
- **导入**：点 **+ 创建插件** 后选择从本地文件夹导入

## 使用方式

- **自动触发** — 描述需求时自动判断并调用匹配的插件能力
- **斜杠命令** — 输入 `/插件名`
- **试用** — 插件卡片点 **Try now** 启动测试会话

## 管理

入口三个：市场右上角「管理」/ 市场左侧分类底部「已安装」/ Qoder IDE 设置的「插件」面板。
设置面板按**用户级 / 项目级**分 Tab，自定义区域底部有「导入」和「+ 新建」。

**禁用插件后其包含的所有组件同时被禁用**，无需逐一操作。

### 组件关联约束

来自插件的组件在各自设置面板中会标记来源插件。
**这些组件由插件统一管理——不支持单独禁用、删除或修改**，需通过所属插件操作。
