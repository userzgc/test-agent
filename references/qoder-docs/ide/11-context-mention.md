# @Mention 上下文引用（Qoder IDE）

> 来源：https://docs.qoder.com/zh/user-guide/chat/context

## 三种添加方式

| 方式 | 操作 | 说明 |
|---|---|---|
| 点击按钮 | 输入框右下角 `@` | 打开选择窗口浏览所有类型 |
| 输入 `@` | 输入后继续键入 | 实时检索文件、目录、规则，高亮匹配字符 |
| 拖拽/粘贴 | 拖放文件或图片到聊天框 | 支持 **md、xmind、xlsx、docx、pdf、jpg、png** |

## 四种上下文类型

| 类型 | 用途 | 典型场景 |
|---|---|---|
| `@file` | 引用代码文件或规则文件 | 查询实现、重构、理解模块 |
| `@folder` | 引用整个目录 | 重构模块结构、生成测试、跨文件查询 |
| `@attachments` | 引用本地文件或图片 | 根据设计稿生成代码、分析文档、处理表格 |
| `@rule` | 引用项目规则 | 按团队风格生成代码、统一规范 |

### `@attachments` 支持的文件类型

| 类型 | 格式 | 场景 |
|---|---|---|
| 图片 | jpg、png | 生成前端代码、分析布局、提取文字 |
| 文档 | md、pdf、docx | 分析内容、提取信息、生成注释 |
| 表格 | xlsx | 分析数据结构、生成处理代码 |
| **思维导图** | **xmind** | **理解架构、生成代码框架** |

> ⭐ **官方原生支持 xmind 作为输入附件**——本项目的历史用例 XMind 可以直接 `@attachments` 丢进来做参考，
> 不需要先转成 md。这一点对「参考历史用例生成新用例」的场景直接可用。

### `@rule` 的双重身份

规则会**嵌入到每次模型调用的系统提示中**，提供持久、可复用的上下文。

> `.qoder/rules` 目录中的 `.md` 文件**既可作为 `@rule` 引用（持久上下文），也可通过 `@file` 搜索（普通文件）**。

规则列表为空时，可通过快捷入口直接创建新规则，无需跳转设置页。

## Add to Chat（细粒度选中）

文件（**包括代码文件和 Spec 文件**）支持选中任意片段后：
- 点击浮窗中的 **Add to Chat**
- 快捷键 `⌘L`（macOS）/ `Ctrl+L`

**会话流中的内容同样可以** ——选中一段回复后 Add to Chat 附加到输入框，便于承接上下文减少重复输入。

## 使用技巧

组合多种上下文：
```
@src/api.js @tests/api.test.js @rule coding-style
为这个 API 模块补充测试用例，确保符合团队编码规范
```

输入 `@` 后列表上方推荐：**当前文件** + **最近打开的 2 个文件**。
