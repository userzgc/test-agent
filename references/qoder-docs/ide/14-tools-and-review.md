# 工具、Diff 审查、文生图、消息队列（Qoder IDE）

> 来源：https://docs.qoder.com/zh/user-guide/chat/tools

## 内置工具分类

| 分类 | 工具 |
|---|---|
| **搜索** | 代码库（语义代码搜索）、文件、代码、目录、**Web 搜索（无需 API 密钥）**、网页内容获取 |
| **编辑** | 修改文件、查看文件 |
| **执行命令** | 运行命令、获取终端输出 |
| **查找问题** | 获取代码问题（「问题」窗口中显示的） |
| **更新记忆** | 基于用户输入更新持久化记忆 |

可与 MCP 服务集成扩展。

## Diff 视图与审查模式

AI 提出的每次修改都以 diff 视图呈现（新增绿 / 删除红 / 上下文中性色）。
⚠️ **代码变更会直接应用**，不满意则点「拒绝」撤销。

| 粒度 | 操作 |
|---|---|
| **变更级** | 每个变更右上角「拒绝」丢弃该更改 |
| **文件级** | 文件底部「拒绝」丢弃当前文件所有修改；可在含待处理更改的文件间导航 |
| **多文件** | 受影响文件名显示在 Chat 面板上方。点「拒绝」统一丢弃全部（**有二次确认**）；点文件名跳转；**悬停某文件名可仅拒绝该文件** |

## 文生图 `/gen-image`

自然语言描述画面 → Agent 生成图片并直接返回预览。
生成的图片支持：**添加到对话**（作为上下文继续问答）、**下载**、**复制到剪贴板**。
在 Quest 中同样可用。

## 消息队列（⭐ 实用）

Agent 执行任务期间可继续输入下一步，新消息进入待发列表按顺序排队。

| 模式 | 队列执行方式 |
|---|---|
| **Ask / Agent** | 默认等当前轮次结束再依次自动执行；可对某条消息点「引导」让 Agent 立即介入 |
| **Experts** | Agent **主动判断时机批量获取**队列消息并接管，无需手动引导 |

**引导（Steer）**：点队列中某条消息的「引导」按钮，立即把该内容交给 Agent，
让它在执行过程中接收新方向或修正要求，**减少打断与重复开始的成本**。
引导触发后模型结合当前任务进度自主判断如何衔接。

队列内其他操作（悬停条目可见）：**拖拽排序**（左侧手柄，即时生效）、
**编辑**（回填输入框，修改后回车更新，位置不变）、**删除**（剩余顺序不变）。

> ⭐ 对本项目的意义：以前「Agent 正在跑，我想补充一句只能等」的情况，
> 现在应该用队列 + 引导。尤其是发现方向跑偏时，**引导比中断重来便宜得多**。
