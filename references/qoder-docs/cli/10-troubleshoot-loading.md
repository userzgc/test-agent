# Memory、Skills 和 Agent 未加载 —— 排查（Qoder CLI）

> 来源：https://docs.qoder.com/zh/cli/troubleshoot-loading
> ⭐ 本页是「资产明明写了却不生效」的官方排查清单，本项目 `.trae/` 资产全失效的直接对照表。

## 记忆 / 项目说明未加载

项目说明文件（默认 `AGENTS.md`）未被载入上下文时：

| 检查项 | 说明 |
|---|---|
| **文件名** | 确认与 `context.fileName` 一致（默认 `AGENTS.md`，可配数组） |
| **发现边界** | 向上查找**遇到 `context.memoryBoundaryMarkers`（默认 `.git`）的目录即停止**。文件在边界之外不会被发现 |
| **额外目录** | **默认仅扫描当前目录**。要从额外可信目录加载记忆需开 `context.loadMemoryFromIncludeDirectories` |
| **发现上限** | `context.discoveryMaxDirs`（默认 **200**）限制搜索目录数，超大仓库可能触上限 |
| **文件夹信任** | 未信任的目录不会加载项目内容 |
| **自查命令** | **`/memory`** 查看当前加载的记忆来源 |

## Skills 未加载

| 检查项 | 说明 |
|---|---|
| **自查命令** | **`/skills`** 查看已加载列表 |
| **目录结构** | 必须是 `skills/<name>/SKILL.md`，层级与文件名都要对 |
| **来源优先级** | 内置 < 插件 < **项目级** < **用户级**，同名时高优先级覆盖低优先级 |
| **条件 Skill** | 仅在**文件路径匹配**时激活，未匹配则不出现在列表里（不是坏了） |
| **功能开关** | `/skills` 需要 Skills 支持与**管理员权限开启** |

> ⚠️ 注意优先级方向：**用户级 > 项目级**。
> 这与上一段落盘的 `ide/02-skills.md` 里「同名时项目级优先」的说法相反 —— **以本页为准**。

## Agent 未加载

| 检查项 | 说明 |
|---|---|
| **自查命令** | **`/agents`** 查看已加载的 Agent |
| **位置与格式** | 定义文件须在 `agents/` 目录下，格式正确 |
| **被禁用** | 检查 `agents.overrides` 是否把目标 Agent 设为禁用 |
| **临时加载** | 通过 `--agents` 加载的额外定义**仅本次会话有效** |

## 重新加载（不一定要重启）

| 对象 | 重载方式 |
|---|---|
| 记忆 | `/memory` |
| Skills | **`/skills reload`** |
| Agent | **`/agents reload`** |
| 自定义命令 | `/commands` |

上述无效时重启 Qoder CLI；部分加载相关配置标注「需重启」。

## 🎯 三个自查命令是本项目最该先跑的动作

在讨论「要不要迁移 `.trae/`」之前，先跑一遍 `/skills`、`/agents`、`/memory`，
用实际加载结果代替猜测 —— 这比读任何文档都直接。
