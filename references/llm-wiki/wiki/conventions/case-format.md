# 测试用例格式规范

## XMind 结构（4层固定层级）

```
根节点：活动名称
├── 一级：业务模块
│   ├── 二级：场景分类
│   │   ├── 三级：测试点标题
│   │   │   ├── 四级：预期结果1
│   │   │   └── 四级：预期结果2
```

## 层级定义

| 层级 | 内容 | 示例 |
|------|------|------|
| 一级 | 业务模块 | 碎片获取、退款回收 |
| 二级 | 场景分类 | 正向支付、边界金额、并发、异常 |
| 三级 | 测试点标题 | 微信小程序自提≥12元下单 |
| 四级 | 预期结果 | 发1枚碎片，城市碎片+1，全局碎片+1 |

## 禁止内容
- ❌ UI点击步骤（"点击XX按钮→跳转XX页面"）
- ❌ 底层实现细节（"DB写入XX字段""缓存清除"）
- ❌ 独立的"前置条件"节点
- ❌ 空节点或占位符

## 标签前缀（可选）
- 【功】功能正向
- 【边】边界场景
- 【异】异常场景
- 【并】并发场景
- 【幂】幂等场景

## 版本管理
- 每次修改生成新版本，文件名带版本号
- v1 → v2 → v3，不覆盖旧文件
- 评审修改记录在 docs/CHANGELOG.md
