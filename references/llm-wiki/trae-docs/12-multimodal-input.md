# 多模态输入（图片与语音）

> 来源：[Trae 官方文档 - 图片与语音输入](https://www.volcengine.com/docs/86677/2206994)
> 获取时间：2026-08-06

## 概述

Trae 提供多模态输入能力，支持将图片作为对话上下文输入给 AI，或通过语音方式与 AI 进行交互。

## 图片输入

### 支持的图片类型
- 错误截图
- 设计草图/设计稿
- 参考样式
- 其他图片

### 使用方式

| 方式 | 操作 |
|---|---|
| 拖放图片 | 从外部来源或项目文件树拖入对话输入框 |
| 粘贴图片 | 复制到剪贴板后在输入框粘贴（Cmd/Ctrl+V） |
| 图片选择器 | 点击输入框左下角的图片按钮，从本地选择 |

### 示例用法
- 上传报错信息截图，让 AI 协助解决错误
- 上传设计稿，让 AI 输出相关代码
- 上传参考样式，让 AI 还原 UI

## 语音输入

### 前提条件
- 首次启用需授权麦克风访问权限
  - macOS：系统设置 > 隐私 & 安全性 > 麦克风
  - Windows：开始 > 设置 > 隐私 & 安全 > 应用权限 > 麦克风

### 使用方式
1. 在 AI 对话输入框右下角，点击语音输入按钮
2. 用语音描述需求
3. Trae 会将语音实时转录为文字
4. 点击停止语音输入按钮
5. 语音内容以文字形式展示在输入框中，支持手动修改

## 重要限制：模型视觉能力

### 问题
Trae IDE 支持图片输入，但能否"看到"图片内容取决于所用模型：

| 模型 | 视觉能力 | 备注 |
|---|---|---|
| GLM-5.2 | ❌ 不支持 | 纯文本模型，上传图片报错 code:20041 |
| Kimi-K2.7-Code | ✅ 支持 | 多模态，适合截图分析、设计稿识别 |
| Claude 3.5 Sonnet | ✅ 支持 | 多模态 |

### 报错示例
```
code: 20041
message: "The model is not a VLM (Vision Language Model). Please use text-only prompts."
```

### 解决方案
1. 切换到支持视觉的模型（如 Kimi-K2.7-Code）
2. 或使用 `design-extractor` agent 走结构化数据/OCR 路径
3. 配置方式：设置 → 模型 → 添加模型 → 开启"多模态"开关

## 与 design-extractor agent 的配合

| 场景 | 策略 |
|---|---|
| 模型支持视觉 | 用户直接拖图片到对话，agent 分析 |
| 模型不支持视觉 | agent 下载图片到本地 → OCR 提取文字 / 提示用户切换模型 |
| 有结构化数据 | 蓝湖 MCP / 导出 JSON → agent 直接解析（无需视觉） |
