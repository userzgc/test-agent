# Trae IDE 概览

> 来源：https://docs.trae.cn/ide/what-is-trae

## 是什么
TRAE IDE 深度融合 AI 能力，是能理解需求、调用工具并独立完成各类开发任务的"AI 开发工程师"。

## 两种版本
- **个人版**：完整 IDE 核心能力，多种语言与框架，适合独立开发者
- **企业版**：在个人版基础上增加团队协作、权限管理、资源监控、企业模型接入

## 双重模式
| 模式 | 特点 | 适用场景 |
|------|------|---------|
| IDE 模式 | 传统开发方式，开发者全程自主控制 | 需要掌控感、精确修改 |
| SOLO 模式 | AI 主导，自动规划任务全流程 | 从需求到产出快速推进 |

切换位置：界面左上角

## 核心能力
1. **智能体（Agent）** — 内置 Builder / Builder with MCP，可自定义
2. **CUE 智能编程助手** — 代码补全、多行修改、智能导入、智能重命名
3. **MCP Server** — 接入外部工具和服务
4. **上下文** — 代码仓库、文件、文件夹、代码块、网页、文档集
5. **规则（Rules）** — 规范 AI 行为
6. **技能（Skill）** — 可复用的专业能力封装
7. **Hook** — 事件触发的自动化动作
8. **SOLO Coder** — 面向复杂项目的 AI 智能体

## 支持的语言
前端（JS/TS/Vue/React/Svelte/Angular/Tailwind）、后端（Python/Java/Go/C#/PHP/Node/Ruby/Rust/C++）、移动端（Swift/Kotlin/Dart/RN）、数据库/脚本（SQL/Shell/Markdown）、数据/AI（Pandas/PyTorch）、配置（JSON/YAML/Dockerfile/K8s/Terraform）

## 产品形态
- TRAE IDE（独立 IDE，基于 VS Code 内核深度定制）
- TRAE 插件（VS Code / JetBrains）
- TRAE CLI（命令行 Code Agent）
- TRAE Work（AI 原生工作台，Work + Code 双模式）

## 系统要求
- macOS 12.0+ / Windows 10+ / Ubuntu 20.04+
- 推荐 8GB+ RAM（复杂项目 16GB）
- 需要稳定互联网连接（AI 功能依赖）
