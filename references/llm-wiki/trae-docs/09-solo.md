# SOLO 模式

> 来源：https://docs.trae.cn/ide/solo

## 是什么
SOLO 模式让 AI 主导任务，自动规划并完成从需求理解、代码生成、测试到成果预览的全流程。
与 IDE 模式对应，IDE 模式是开发者全程自主控制。

## 两种形态
- **SOLO 桌面版** — 独立应用
- **SOLO 网页版** — 浏览器访问

## SOLO Coder
SOLO Coder 是 SOLO 模式配备的专属 Coding Agent，面向复杂项目开发。

### 能力
- 从自然语言输入到可执行产出
- 需求迭代到架构重构全流程
- 自动规划任务步骤
- 代码生成 + 测试 + 预览

## SOLO 模式 vs IDE 模式
| 维度 | IDE 模式 | SOLO 模式 |
|------|---------|----------|
| 主导者 | 开发者 | AI |
| 控制感 | 强 | 弱（自动化） |
| 适用 | 精确修改、深度调试 | 从 0 到 1、快速原型 |
| 产物预览 | 需手动启动 | 自动预览 |
| 模式切换 | 左上角切换 | 左上角切换 |

## SOLO 模式专属功能
- **Spec 模式** — 规格驱动开发
- **Plan 模式** — 计划驱动（已移除开关，改用 `/plan` 和 `/spec` 指令切换）
- **Markdown 预览** — 打开 .md 文件默认进入可实时编辑的预览视图
- **多任务面板** — 管理多个并行任务
- **导出历史对话** — 多任务面板可导出

## 引用历史对话
SOLO 模式下，输入框内用 `#` 引用历史对话。

## 适用场景
- 快速原型验证
- 从需求文档直接生成代码
- 全新项目从 0 搭建
- 探索性开发
