# 上下文（Context）

> 来源：https://docs.trae.cn/ide/context

## 是什么
Trae 能理解多种类型的信息作为 AI 对话的上下文。

## 上下文类型

| 类型 | 引用方式 | 说明 |
|------|---------|------|
| 代码仓库 | `@` 选择 | 整个仓库作为上下文 |
| 文件夹 | `@` 选择 | 指定目录 |
| 文件 | `#文件名` 或 `@` 选择 | 单个文件 |
| 代码块 | `#` 选择 | 文件中的特定代码段 |
| 网页 | `#` | 网页内容作为上下文 |
| 文档集 | `#docs` | 上传的文档集 |
| Problems | `#Problems` | 编辑器诊断的问题 |
| 历史对话 | `#` | 引用历史对话内容（IDE 和 SOLO 模式） |
| 终端输出 | `@` | 终端卡片内容 |
| 预览窗口 | `@` | 预览窗口信息 |

## 使用方式
在对话框输入 `@` 或 `#` 触发引用选择器。

## 文档集
上传文档作为 AI 对话的上下文，支持多种格式。

## 最佳实践
- **精准引用**：只引用必要的文件，避免上下文过大
- **分层引用**：先 `@` 整个模块了解结构，再 `#` 具体文件深入
- **组合上下文**：`#需求文档` + `#接口文档` + `@相关代码` 一起给
- **Problems 上下文**：让 AI 看到所有诊断问题，修复更准

## 注意
- 上下文越大，Token 消耗越多，响应越慢
- 网页内容需要可访问的 URL
- 文档集需要预先上传
