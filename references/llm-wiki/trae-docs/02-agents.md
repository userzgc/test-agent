# 智能体（Agent）

> 来源：https://docs.trae.cn/ide/agent

## 是什么
智能体是面向不同开发场景的编程助手，可自主探索代码库、调用工具、多步规划完成任务。

## 工作流
1. **需求分析** — 理解目标和代码库上下文
2. **代码研究** — 搜索代码、文档、在线资源
3. **方案设计** — 分解步骤、动态优化
4. **实施变更** — 代码修改、终端命令、依赖安装
5. **交付验收** — 验证后总结修改

## 内置智能体
- **Builder** — 从 0 开发项目，使用文件系统/终端/Web搜索等工具
- **Builder with MCP** — 在 Builder 基础上自动加载所有已配置的 MCP Server（不可编辑）

## 创建自定义智能体
1. 设置 > Agents，或对话框 `@Agent` > `+ 创建 Agent`
2. 配置项：
   - **头像**（可选）
   - **名称**
   - **提示词（Prompt）** — 定义人设、语气、工作流、工具使用时机、规则
   - **工具** — 选择可用的工具：
     - MCP servers（可加多个）
     - 文件系统（增删改查）
     - 终端（运行命令）
     - Web 搜索
     - 预览（UI 预览窗口）

## 使用
对话框输入 `@` 或点 `@Agent`，从列表选择。

## 管理
- 修改配置
- 分享到 X 或复制链接
- 删除
- 导入他人分享的 Agent（点链接 → 在 Trae 中打开 → Get Now）

## Auto-Run 模式
适用于所有 Agent。开启后 Agent 自动执行认为安全的命令和 MCP Server。
- 黑名单（默认 rm、kill、chmod）需用户确认
- 黑名单以外的命令自动执行
- ⚠️ 有外部 prompt 注入风险

## 项目级 Agent 配置
项目根目录下 `.trae/agents/<agent-name>/agent.md` 定义项目级 Agent，团队成员共享。
