# 知识库结构定义

## 目录结构
```
references/llm-wiki/
├── SCHEMA.md           # 本文件
├── wiki/               # 知识页面
│   ├── confluence.md   # Confluence 访问方式
│   ├── feishu.md       # 飞书 CLI 使用
│   ├── yapi.md         # YAPI 接口解析
│   ├── xmind.md        # XMind 文件格式
│   ├── activities/     # 活动知识
│   │   ├── city-badge.md    # 城市徽章活动
│   │   └── buy-a-gift-b.md  # 买A赠B活动
│   └── conventions/    # 测试规范
│       ├── case-format.md   # 用例格式规范
│       └── review-checklist.md # 评审检查清单
```

## 页面模板
每个知识页面包含：
- **概述**：一句话说明
- **关键信息**：核心规则、配置、流程
- **关联资源**：文档链接、代码位置
- **变更记录**：更新历史
