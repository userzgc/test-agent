## 2. 高优先级发现（必须修改）

### H1 【漏测】赠品取消后库存回滚（逆向流程）

- **问题**：用户选了周边赠品后又取消选择，库存是否回滚？
- **为什么重要**：库存不回滚 = 用户取消后其他人买不到 = 资损 + 客诉
- **建议补充**：
  ```
  S56 【P0 异常】赠品选择后取消 → 库存回滚
  前置：周边赠品库存=5
  步骤：1. 选周边赠品（库存 5→4）
        2. 取消该赠品
        3. 查看库存
  预期：1. 库存回滚为 5
        2. 其他人可选
  ```

### H2 【弱预期】S52 寄存券+周边赠品的预期可能错误

- **问题**：我写"寄存券模式下赠品选择器不出现周边商品"，但 V2 §3.3.3 原文是"validateGiftProductTypes 仅由当单立享分支调用"——这说的是**校验逻辑不走**，不代表**选择器不显示周边**
- **为什么重要**：如果选择器还是显示周边，运营选了周边后切到"下次使用"，保存时是否拦截？这点没覆盖
- **建议修改 S52**：
  ```
  预期结果改为：
  1. 需确认：赠品选择器是按活动类型过滤还是全量展示
  2. 若全量展示：运营在"下次使用"模式下选周边 → 保存是否被拦截
  3. 若按活动类型过滤：寄存券模式下赠品选择器不出现周边
  → 标为 Q10 待确认
  ```

### H3 【漏测】活动进行中编辑限制

- **问题**：V2 §7 提到 `checkEditability（进行中活动限制编辑范围）`，但 55 个用例没覆盖
- **为什么重要**：进行中活动改了赠品/结算比例，已下单的分账按老配置还是新配置？
- **建议补充**：
  ```
  S57 【P0 异常】进行中活动编辑限制
  前置：活动进行中（已有用户下单）
  步骤：1. 尝试修改赠品
        2. 尝试修改结算比例
        3. 尝试修改主品组合
  预期：按 checkEditability 规则拦截/放行
  ```

### H4 【漏测】赠品排序展示

- **问题**：一期用例 JSON 第 33 行明确"有排序"，但二期 55 个用例没覆盖
- **为什么重要**：运营配置的赠品顺序如果 C 端不按排序展示，影响用户体验和转化
- **建议补充**：
  ```
  S58 【P1 正向】赠品排序展示
  前置：配置 5 个赠品，sortIndex=1~5
  步骤：1. C端查看赠品列表
  预期：1. 按 sortIndex 升序展示
  ```

### H5 【弱预期】S37-S40 资损用例测试数据不具体

- **问题**：S37 只说"周边赠品单价 50 元"，没区分"现价 vs 原价"，补贴基数按哪个？
- **为什么重要**：补贴基数口径错误 = 分账金额错误 = 财务对账失败
- **建议修改**：
  ```
  S37 测试数据改为：
  - 周边赠品原价 80 元，现价 50 元
  - 补贴基数按现价 50 元（需 Q11 确认：按现价还是原价）
  ```

### H6 【漏测】多组活动交叉边界

- **问题**：S17 只测"组1选齐+组2选齐"和"组1未选齐+组2选齐"，没测"组1选齐后取消某件"
- **为什么重要**：用户先选齐后取消，门槛状态是否正确回滚？
- **建议补充**：
  ```
  S59 【P0 边界】多组选齐后取消某件 → 门槛回滚
  前置：S3 多组活动
  步骤：1. 组1选齐2件、组2选齐1件 → 门槛达成
        2. 组1取消1件 → 门槛应未达成
        3. 查看赠品入口
  预期：1. 取消后赠品入口不可用
        2. 按钮文案回退为"首件已选，去选赠品"
  ```

### H7 【弱预期】S43 周边赠品 100% 无上限的资损验证不充分

- **问题**：只说"注意金额放大"，没说验证什么
- **建议修改 S43**：
  ```
  预期结果补充：
  4. 验证周边赠品 50 元分账是否触发告警（门槛未达成次数/分账金额异常监控）
  5. 验证 subsidyCap 是否为 null（技术方案不强制必填）
  6. 上线后 7 日对账是否覆盖此场景
  ```

### H8 【漏测】赠品数量为 30 时 C 端展示

- **问题**：S8 测了后台配置 30 个赠品，但没测 C 端展示 30 个赠品的样式
- **为什么重要**：30 个赠品在 C 端赠品选择弹窗的展示样式（滚动/分页/折叠）未明确
- **建议补充**：
  ```
  S60 【P2 边界】30 个赠品 C 端展示样式
  前置：活动配置 30 个赠品
  步骤：1. C端进入赠品选择
  预期：1. 30 个赠品正常展示
        2. 滚动/分页样式符合设计稿
  ```
